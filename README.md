# DOSW_PARCIALT1_JuanCruz
Parcial de primer corte de DOSW 


### Patrones de diseño que pueden aplicarse para el caso de estudio 

#### Primer patrón
a. Nombre del patron: Factory Method

b. Tipo de Patrón: Creacional 

c. Justificación: Este patron puede ser utilizado ya que con este se puede crear un metodo factory que ayude con la extensibilidad que se le quiere dar al caso, ya que  este patron  proporciona una interfaz para crear objetos en una superclase, lo que  permite a las subclases alterar el tipo de objetos que se crearán.


### Segundo Patrón 

a. Nombre del patron: Abstract Factory

b. Tipo de Patrón: Creacional 

c. Justificación: Este patron tambien puede ser utilizado ya que permite crear familias de objetos relacionados lo cual puede ayudar a añadir nuevos tipo de funcionalidades o en este caso nuevos tipos de gestiones
